# Доклад наугад

Генератор случайных названий докладов на словаре из программы Дизайн-выходных (Тула, 9–10 октября). От двух до четырёх слов (обычно три; по 10% — два и четыре), согласованные по роду, падежу и одушевлённости. В каждом шестом названии одно случайное слово заменяется на «…».

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны.
В VS Code удобно запускать через расширение Live Server: правка → автообновление.

## Файлы

- `index.html` — разметка слайда и управления
- `style.css` — стили; темы слайда задаются в `THEMES` (в `words.js`)
- `words.js` — словарь: существительные, прилагательные, глаголы, предлоги, имена и фамилии спикеров, должности, компании, секции/залы, цветовые темы
- `script.js` — склонение прилагательных, эвфония предлогов (об/со/во), шаблоны фраз, рендер, история, экспорт слайда в PNG

## Как пополнять словарь

**Существительное** — одна строка в `NOUNS`: шесть падежных форм и род.

```
кнопка кнопки кнопке кнопку кнопкой кнопке f
заказчик заказчика заказчику заказчика заказчиком заказчике ma
креветки креветок креветкам креветок креветками креветках pa
```

Род: `m`, `f`, `n`, `p` (только мн. ч.). Буква `a` означает одушевлённое: от неё зависит винительный падеж прилагательного («приручить ленивого заказчика»). Несклоняемые слова (ИИ, портфолио) записываются шесть раз одинаково.

**Прилагательное** — мужской род именительного падежа в `ADJ`. Склоняются автоматически окончания -ый, -ий после к/г/х и ударное -ой. Не подходят мягкая основа (синий) и шипящая без ударения (хороший): для них нужно расширить `adjForm` в `script.js`.

**Предлог** — пара `['предлог', падеж]`, падеж от 0 до 5: им, род, дат, вин, твор, предл.

## Шаблоны

Массивы `PATTERNS2`, `PATTERNS` и `PATTERNS4` в `script.js` — шаблоны на два, три и четыре слова. Доли длин задаются в `pickPattern`. Слот задаётся так:

- `{k:'noun', c:1}` — существительное в родительном падеже
- `{k:'noun', from:1}` — падеж берётся от предлога в слоте 1
- `{k:'adj', agree:2, c:0}` — прилагательное согласуется с существительным в слоте 2
- `{k:'fixed', t:'как'}` — постоянное слово

Чтобы шаблон выпадал чаще, добавьте его в массив дважды.
